SQL - Structured Query language
- It used to communicate with relational database
- Popular databse - MYSql, MySQL server, PostgreSQL
- Company use - E-commerce, banking, applications

Activities  --> Important command 
- create table
CREATE TABLE student (id INT PRIMARY KEY, name VARCHAR, course VARCHAR);

- insert data
INSERT INTO student VALUES ("sanika", "AIML");

- select 
SELECT * FROM student;

- update 
UPDATE student SET course = "IT" WHERE id = 1;

- delete
DELETE FROM student WHERE id = 1;

**diff between delete,drop.truncate
DELETE → removes selected rows 

TRUNCATE → removes all rows 

DROP → deletes entire table 

**Joins and types
JOIN = combine data from multiple tables based on related columns
INNER JOIN → only matching rows
LEFT JOIN → all rows from left + matching from right
RIGHT JOIN → all rows from right + matching from left
FULL JOIN → all rows from both tables 
CROSS JOIN → all combinations 


**What is ORM 
- Object relational mapping 
- instead of writing sql quries we use js objects 
- without ORM - SELECT * FROM student;
- with ORM - student.findAll();
